Uses an AI to generate FHIR Bundles to represent clinical scenarios. You can select the model to use - haiku is fast but basic, sonnet is slower but more thorough and opus is the most comprehensive, but can take minutes to complete for a complex instruction.
Enter the description of your scenario and the AI will build a representative bundle. You can view the bundle and give additional instructions to refine the content in a conversational manner. Use the 'Start new conversation' to start over. The current conversation is saved in the local browser cache so you can return to it later. If you need to use the bundle elsewhere, there's a 'copy to clipboard' option in the Json tab.

This functionality is experimental and not yet fully robust. If you get an error you can just try again or change the prompt
